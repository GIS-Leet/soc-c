# 시뮬레이터 검증 기록

검증일: 2026-10-04. 대상: `simulator-redesign-draft`의 7개 실험과 목록 페이지. 공개 홈페이지에 배포하지 않은 검토본이다.

## 실행 환경

Windows, Node.js 24.18.0, Playwright 1.63.0 Chromium, axe-core/playwright 4.13.0. 3D 검사는 ANGLE/SwiftShader 소프트웨어 WebGL을 사용했다. 브라우저 검사는 로컬 HTTP 서버를 사용하며 주소는 `SIM_URL`로 지정한다.

## 계산과 기능

최종 결과: 단위·통합 검사 207개 중 204개 통과, 실패 0개, 기존 Firebase 에뮬레이터가 필요한 검사 3개 건너뜀. 8개 페이지 기능 검사, WebGL 대체 보기 4개와 의존성 실패 안내가 통과했다. 접근성 32개 조합에서 axe 위반은 0개였다. 렌더링·기록 제거·페이지 캐시 복귀·지형 장면 검사도 모두 통과했다. 시뮬레이터 검사에서 건너뛴 항목은 없다.

태양 고도와 사면의 수광 비율을 독립적인 벡터 내적과 비교한다. 자전축과 공전 위치의 적위, 극야·백야, 극점의 분점 규약, 지평선 아래의 남중 고도를 확인한다. 일평균 일사는 12,000개 시간 표본의 수치 적분 및 전 지구 면적 가중 평균과 비교한다. 지구 확대와 궤도 보기, 월·위도·기울기 조작은 같은 수치 모형을 사용한다.

지형의 시드 재현성, 평면 보간·경사·등고선, 사면 완화의 높이 합 보존과 극값 범위, 실행 취소·다시 실행을 확인한다. 세계 지형과 지각 작용은 모든 시나리오의 단계와 유한한 단면 값을 검사한다. ITCZ는 정의된 개념 모형의 범위와 유형 차이를 검사하며 관측 강수량 적합도를 주장하지 않는다. 서울의 거리는 구면 기준값과 비교하고 시기·레이어·가정 속도 조작을 확인한다.

기록 기능 제거 검사는 화면 요소의 부재뿐 아니라 실제 조작 후 노트 저장 호출이 없는지 확인한다. 과거 브라우저 저장값은 유지한다. 화질과 밝은·어두운 테마 전환이 측정값을 바꾸지 않는지 비교한다. 내부 지형 직렬화 검사는 실행 취소 등에서 계속 필요하며 사용자용 파일 입출력 기능을 의미하지 않는다.

## 렌더링과 시각 검토

4개 3D 페이지 모두 안정된 정지 상태의 1초 동안 추가 렌더링 0회, 화면 밖 1초 동안 0회를 확인했다. 재생 중에는 렌더링이 진행되고 모바일 크기로 바꾼 뒤에도 다시 그려진다. 이는 그리기 호출 수이며 실제 학교 기기의 FPS, 배터리 또는 최소 사양 측정값은 아니다.

7개 실험과 목록의 밝은·어두운·모바일 화면, 세계 지형의 7개 시나리오와 빙하 단계, 지각 작용의 5개 시나리오를 검토했다. [장면별 화면](simulator-scene-review.md)에서 최종 이미지를 볼 수 있다. 해안 물의 절단면, 얼음 단면, 단층면, 지구 화면 크기 변경 후 검은 화면 문제를 수정했다.

## 해석의 한계

자동 접근성 검사는 전체 WCAG 적합성 인증이나 보조 기술 사용자 평가를 대신하지 않는다. Safari·Firefox, 실물 태블릿, 저사양 학교 기기의 장시간 검사는 별도로 필요하다. 외부 글꼴과 서울 배경 지도에는 네트워크가 필요하다. NASA 지표 영상은 로컬 자산으로 제공한다.

사진 재질과 그림의 현실감은 모형의 실측 적합도 증거가 아니다. 학생 학습 효과, 평가 도구의 타당도·신뢰도, 교사 전문가 평정은 아직 측정하지 않았다. 출판을 위한 후속 절차는 [연구 평가 계획](simulator-research-protocol.md)에 기록했다.
