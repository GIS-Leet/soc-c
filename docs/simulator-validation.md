# 시뮬레이터 검증 기록

검증일: 2026-10-03. 대상: `simulator-redesign-draft`의 모형·기록 형식 v2. 공개 홈페이지에 배포하지 않은 검토본이다. 결과는 아래 환경과 검사 범위에 한정한다.

## 실행 환경

Windows, Node.js 24.18.0, Playwright 1.63.0의 Chromium, axe-core/playwright 4.13.0. 3D 검사는 ANGLE/SwiftShader 소프트웨어 WebGL을 사용했다. 각 명령은 저장소 루트에서 실행한다. 접근성·성능 검사에는 별도의 로컬 HTTP 서버가 필요하다. 실행 방법은 README를 따른다.

## 계산 검증

태양 고도와 사면의 수광 비율을 벡터 내적으로 검증했다. 자전축과 공전 위치에서 계산한 적위가 수식과 일치하는지 확인했다. 극야·백야, 극점의 춘추분 규약, 지평선 아래의 음수 고도를 포함했다. 일평균 일사는 12,000개 시각 표본의 수치 적분과 비교했으며, 전 지구 면적 가중 평균이 태양 상수의 1/4인지를 확인했다. NOAA 달력 근사식은 별도 기준 사례로 검사하며, 화면의 이상화된 월별 공전 모형과 구분한다.

지형 검사는 난수 시드 재현성, 평면의 보간·경사, 사면 완화의 높이 총합 보존과 극값 범위, 평탄면 유지, 등고선의 높이를 확인한다. Float32 지형 격자는 저장 후 비트 정밀도를 보존한다. 이동 거리에는 알려진 구면 기준값을 사용한다. ITCZ 지수는 정의한 개념 모형의 경계·대칭·유형 차이를 검증하며 실제 강수 관측 적합도를 검증한 것이 아니다.

기록 검사에는 다른 페이지·버전, 잘못된 조건, 지나치게 큰 파일, 위험한 키의 거부와 CSV 수식 삽입 방지를 포함한다. 음수인 수치 데이터는 숫자로 유지한다. 파일 작성자나 측정값의 진위를 인증하지는 않는다.

## 브라우저 검증

320·390·768·1440px 너비에서 가로 넘침과 주요 조작을 확인했다. 모든 지형 시나리오와 단계, 재생·정지, 극지방 위도, 사면 기울기, ITCZ 유형, 서울 성장 단계와 레이어를 검사했다. 지형에서는 조각·단면·원상 복원·시드·사면 완화·실행 취소·다시 실행·등고선·예시 지형을 확인했다.

각 실험에서 조건 기록 후 다시 불러온 조작 상태와 측정값이 원래 기록과 정확히 일치했다. 지형은 아직 적용하지 않은 입력 시드 대신 실제 생성에 사용한 시드를 기록한다. JSON 가져오기·백업·잘못된 파일 거부, 노트 새로고침 유지, PNG/SVG 그림 내보내기, CSV, 8개 기록 한도, 노트가 제외된 조건 공유를 확인했다.

WebGL을 강제로 사용할 수 없게 한 네 페이지에서 2D 대체 보기와 수치 조작을 확인했다. 필수 모듈 로딩 실패 시 복구 안내가 나타나는지 확인했다. 데스크톱·모바일·어두운 테마의 대표 화면, 탐구 기록, 인쇄용 화면을 육안 검토했다.

## 렌더링 검사 해석

1366×900 Chromium에서 초기 상태를 안정시킨 뒤 검사했다. 네 페이지 모두 정지한 화면의 1초간 새 렌더링 횟수 0, 화면 밖의 1초간 새 렌더링 횟수 0이었다. 재생 중에는 모두 렌더링이 진행됐다. 렌더링 계수는 스케줄러가 수행한 그리기 호출이며 사용자 기기의 실제 FPS·배터리 소모·최저 사양을 측정한 결과가 아니다. 대기 상태 설정을 일정하게 하기 위해 reduced-motion 환경을 사용했다.

## 아직 입증하지 않은 사항

자동 접근성 검사는 전체 WCAG 준수 인증이나 스크린리더 사용자 평가를 대신하지 않는다. Safari·Firefox·실물 태블릿·저사양 학교 기기의 장시간 검사는 별도로 필요하다. 외부 글꼴과 서울 배경지도에는 네트워크가 필요하다. 개념적 지형·수렴대·교통 모형은 실측 예측 모형이 아니다.

학생 학습 효과, 검사 도구의 타당도·신뢰도, 교사 전문가 평정은 아직 측정하지 않았다. 출판을 위한 후속 절차는 [연구 평가 계획](simulator-research-protocol.md)에 제시했다. 재현할 때는 사용한 Git 커밋과 모형 버전, 조건 JSON을 함께 기록한다.
