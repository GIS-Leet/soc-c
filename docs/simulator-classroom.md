# 교실에서 사용하는 Geographia Lab

## 교사 시연과 학생 탐구

첫 실험은 학생에게 답을 먼저 보여주기보다 결과를 예측하게 한다. 한 번에 조건 하나만 바꾸고, ‘현재 조건 기록’으로 전후를 남긴다. 화면 아래 탐구 노트에서 관찰한 수치와 설명을 연결한다. 교사용 해설은 기본적으로 접혀 있다.

‘수업 화면’은 노트와 머리말을 접어 시뮬레이션 공간을 넓힌다. 학생에게 돌려줄 때는 ‘탐구 화면으로’를 누른다. 화면 확대·드래그를 쓰기 어려운 경우 슬라이더, 단계 버튼, 지형의 X/Z 좌표와 ‘선택 위치에 적용’을 사용한다. 실제 기기에서 느리면 화질을 절전으로 바꾼다.

| 실험 | 첫 과제 | 두 번째 과제 | 수업에서 확인할 증거 |
|---|---|---|---|
| 태양 | 30°·60°·90° 비교 | 사면 −20°·0°·+20° | 면적 배율과 에너지 비율 |
| 계절 | 기울기 23.5°와 0° | 반대 반구와 극지방 | 낮 길이·남중 고도·일평균 일사 |
| 수렴대 | 적도와 20°N | 대륙형과 해양형 | 월별 지수의 최대와 이동 폭 |
| 지형 | 해수면만 바꾸기 | 사면 완화와 실행 취소 | 비고·경사·육지 비율·수지 |
| 지각 작용 | 습곡과 단층 | 하천과 융기 | 지층 연속성과 중앙 단면 |
| 세계 지형 | V자와 U자 | 칼데라와 돌리네 | 형태와 형성 과정의 구분 |
| 서울 | 같은 거리, 다른 속도 | 위치 자료와 다핵화 | 직선거리·가상 시간·필요한 추가 자료 |

## 10분 탐구 예시: 같은 빛, 다른 면적

1. 2분 — 고도 30°와 60°에서 에너지 차이를 예측한다. 사면 기울기는 0°로 둔다.
2. 5분 — 30°·60°·90° 조건을 기록한다. 면적 배율과 에너지 비율의 곱을 확인한다. 처음 예측과 다른 점을 적는다.
3. 3분 — ‘같은 빛이 더 넓은 면적에 퍼진다’는 설명을 수치로 뒷받침한다. 이 결과만으로 기온을 구할 수 없는 이유도 적는다.

빠른 학생은 사면 기울기를 바꾸되, 고도까지 동시에 바꾸지 않도록 한다. 교사는 ‘무엇을 같게 두었나’, ‘어느 기록이 그 설명을 뒷받침하나’, ‘이 모형 밖에서 확인할 것은 무엇인가’를 질문한다.

## 저장과 제출

- 노트는 브라우저별로 따로 저장된다. 같은 계정으로 로그인해도 다른 기기에 동기화되지 않는다.
- 공유 기기에서는 수업 끝에 JSON 실험 파일을 저장한다. 파일을 학생이 선택한 학교 제출 경로로 직접 제출한다. 시뮬레이터에는 자동 전송 기능이 없다.
- JSON에는 노트도 들어간다. 조건 링크에는 노트와 비교 기록이 들어가지 않는다. 직접 수정한 지형은 URL 길이 제한 때문에 JSON 파일로 공유한다.
- CSV는 비교표 분석용이다. 그림과 인쇄 보고서를 함께 사용할 수 있지만, 재현이 필요하면 JSON도 보관한다.
- 다른 파일을 열면 기존 기록이 있는 경우 백업 파일이 먼저 내려받아진다. 자동 다운로드가 차단된 브라우저에서는 먼저 ‘실험 파일 저장’을 눌러 직접 보관한다.

## 해석 시 유의할 점

월·해수면·강수 지수·이동시간의 의미는 각 실험의 ‘모형의 범위’에서 확인한다. 지도처럼 보인다는 이유로 모두 관측 자료라고 설명하지 않는다. 특히 한반도 참조 이미지, ITCZ의 강수 지수, 서울의 가상 이동시간은 실측 자료가 아니다.

## 로컬 검토

개편본은 `simulator-redesign-draft` 브랜치에서 검토한다. 공개 `main`은 정비 안내를 유지한다. 미리보기는 저장소 작업 폴더에서 `python -m http.server 8770 --bind 127.0.0.1` 후 `http://127.0.0.1:8770/simulators.html`을 연다. 개발 검증은 `npm ci`, `npx playwright install chromium`, `npm run test:simulators` 순서다. 접근성 검사는 로컬 서버가 열린 상태에서 `node scripts/check-simulator-accessibility.mjs`로 실행한다.
