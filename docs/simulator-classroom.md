# Geographia Lab 교실 활용

2026-10-04 개편본. 화면은 시뮬레이션, 조작 도구, 계산값과 설명으로 구성한다. 탐구 노트·조건 기록·비교 표·파일 저장·보고서 인쇄 기능은 사용자 요청에 따라 제거했다. 예전 브라우저 기록을 삭제하거나 덮어쓰지는 않는다.

‘수업 화면’은 조작 패널과 머리말을 접고 장면을 넓힌다. ‘기본 화면’으로 돌아오면 조작 도구가 나타난다. 화면이 느리면 화질을 ‘절전’으로 바꾼다. 지형은 X/Z 좌표와 ‘선택 위치에 적용’으로도 조작할 수 있다.

| 실험        | 조작                              | 관찰                                      |
| ----------- | --------------------------------- | ----------------------------------------- |
| 태양 고도   | 고도·사면 기울기                  | 법선·입사각·수광 면적과 에너지 비율       |
| 지구와 계절 | 월·위도·기울기·태양시             | 지구 확대/공전 궤도, 낮 길이·일사량       |
| 적도 수렴대 | 월·관찰 위도·이동 유형            | 위성 지표 배경 위 개념 구름대와 월별 지수 |
| 지형 편집   | 융기·침식·평탄화·해수면           | 사진 재질 지표·단면·등고선·육지 비율      |
| 지각 작용   | 지형과 형성 단계                  | 습곡의 지층, 분리된 단층면, 하천 변화     |
| 세계 지형   | 7개 주제와 단계                   | 칼데라·주상절리·빙하·돌리네·해안          |
| 서울        | 성장 단계·레이어·대표점·가정 속도 | 신도시 분포·직선거리·가상 이동시간        |

한 번에 조건 하나를 바꾸며 전후를 비교한다. 별도 기록이 필요하면 수업에서 사용하는 종이나 학습 도구를 사용한다. 시뮬레이터 자체는 학생 기록을 수집하지 않는다.

## 표현의 범위

각 화면의 ‘모형의 범위와 근거’에 계산식과 가정이 있다. 지형은 실측 수치표고모형이 아니며 사진 재질은 실제 암석 성분이나 식생 조사 결과가 아니다. NASA 지표 영상은 2004년 6월 합성 영상으로 월 조작과 연동하지 않는다. 수렴대의 구름·강수 지수, 서울의 연결축과 이동시간은 교육용 개념 표현이다.

## 로컬 검토

개편본은 `simulator-redesign-draft` 브랜치에 있다. 공개 `main`은 ‘개편 중’ 안내를 유지한다. 해당 작업 폴더에서 `python -m http.server 8770 --bind 127.0.0.1`을 실행하고 `http://127.0.0.1:8770/simulators.html`을 연다. 검증 명령과 실제 결과는 [검증 기록](simulator-validation.md)에 정리한다.
