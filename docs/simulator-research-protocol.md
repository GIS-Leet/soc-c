# 교육 연구를 위한 평가 계획 — 시행 전 문서

## 현재 증거의 범위

현재 산출물은 구현, 모형 명세, 자동 검증과 수업 활동이다. 학생 대상 실험·면담·교사 전문가 평정·실제 기기의 장기 사용성 평가는 아직 수행하지 않았다. 따라서 학습 효과, 사용성 점수, 효과 크기 또는 통계적 유의성을 보고하지 않는다. 이 문서는 그 평가를 수행할 때 쓸 수 있는 계획이다.

## 연구 질문

1. 조건을 통제하고 실험 기록을 비교하는 활동이 학생의 인과 설명에 어떤 변화를 주는가?
2. 같은 현상을 3D·단면·수치로 연결하는 과정에서 어떤 오개념이 유지되거나 수정되는가?
3. 교사 시연, 학생 개별 탐구, 서로 다른 기기에서 어떤 조작상의 어려움이 나타나는가?

설계 근거로 [Podolefsky, Moore, Perkins의 implicit scaffolding 연구](https://arxiv.org/abs/1306.6544)와 [PhET 연구 자료](https://phet.colorado.edu/en/research)를 참고한다. 이는 본 도구의 효과가 이미 입증되었다는 의미가 아니다.

## 1단계: 전문가 검토

지리·지구과학 교사에게 모형 명세, 과제, 대표 화면, 기준 계산을 함께 제공한다. 각 실험에 대해 과학적 타당성, 교육과정 적합성, 예상 오개념, 가정의 명시성을 평정하고 수정 근거를 남긴다. 응력·유동을 계산하지 않는 형태 모형을 실제 물리 모형처럼 해석하게 하는 표현이 있는지 우선 확인한다. 평정자 수와 전문성, 불일치 처리 절차를 실제 시행 전에 정한다.

## 2단계: 생각 말하기 사용성 탐구

학생이 ‘조건 하나 바꾸기 → 전후 기록 → 원래 조건으로 복귀 → 설명 작성’을 수행하는 동안 막히는 지점을 관찰한다. 필요시 키보드 조작과 2D 대체 보기를 포함한다. 개별 발화, 오류, 교사의 개입은 학생 동의와 학교의 연구 절차에 따라 최소한으로 기록한다. 이름·학번을 시뮬레이터 노트에 요구하지 않는다.

관찰 항목: 과제 이해, 조작할 변수 찾기, 통제 변수 유지, 기록 의미 이해, 그림과 수치 연결, 저장·복원 성공, 개념 모형과 실측 자료 구별. 횟수와 소요시간의 측정 시작·종료 기준을 사전에 정한다.

## 3단계: 수업 평가

수업 여건에 따라 비교 집단 또는 반복 측정 설계를 택한다. 표본 수는 예상 효과 크기·집단 구조·탈락 가능성을 고려한 검정력 분석으로 결정한다. 임의의 학생 수를 ‘충분한 표본’으로 지정하지 않는다. 학급 단위 배정이면 학생의 관측치를 독립 표본처럼 처리하지 않도록 분석 계획에 학급 구조를 포함한다.

처치 조건에서 사용한 버전, 과제, 시연 시간, 교사 발문과 학생 활동 시간을 기록한다. 비교 조건도 같은 학습 목표와 수업 시간을 갖도록 설계하되 구체적인 차이를 명시한다. 사전 지식, 기기 접근성, 교사 효과와 노출 시간을 가능한 한 측정한다.

## 개념 문항 예시 — 검사 도구로 사용하기 전 내용 타당도 검토 필요

1. 수평면에 태양 고도 30°와 90°로 같은 빛다발이 들어올 때 수광 비율을 비교하고 이유를 설명하시오.
2. 자전축 기울기가 0°인 원 궤도 지구에서 같은 위도의 남중 고도와 낮 길이는 한 해 동안 어떻게 변하는가?
3. 같은 위도를 이동하는 수렴대가 1년에 두 번 통과할 때 상대 강수 지수에 어떤 패턴이 가능한가? 실제 강수와 같다고 단정할 수 없는 이유도 쓰시오.
4. 같은 지형에서 해수면만 올렸을 때 육지 비율의 변화가 일정하지 않을 수 있는 이유를 설명하시오.
5. 오목한 단면 하나만 보고 칼데라인지 돌리네인지 확정할 수 있는가? 추가 증거를 제시하시오.
6. 가정 속도가 두 배가 되었는데 접근·대기시간을 포함한 전체 시간이 절반이 되지 않는 이유를 설명하시오.

문항의 표현·난이도·정답 근거를 전문가 검토하고 소규모 예비 검사를 통해 수정한다. 동일 문항 반복에 따른 기억 효과를 고려해 동형 문항 또는 전이 과제를 검토한다. 단순 조작 숙련을 개념 이해로 간주하지 않는다.

## 설명 루브릭 초안

각 항목 0–2점, 총 8점이다. 최종 채점 기준과 예시 답안은 전문가 검토 후 고정한다.

| 항목 | 0점 | 1점 | 2점 |
|---|---|---|---|
| 조건 통제 | 무엇을 바꿨는지 불명확 | 조작 변수만 제시 | 조작·통제 변수를 구분 |
| 증거 사용 | 근거 없음 | 결과를 정성적으로 언급 | 비교 조건과 측정값을 정확히 연결 |
| 개념 설명 | 관련 없는 설명 | 관련 개념이 있으나 연결이 약함 | 증거와 인과 설명을 일관되게 연결 |
| 모형의 한계 | 모형을 현실과 동일시 | 한계를 막연히 언급 | 구체적 생략 조건과 추가 자료를 제안 |

채점자는 학생의 집단 정보를 가릴 수 있으면 가린다. 독립 채점과 불일치 조정 기록을 남기고, 자료에 맞는 채점자 간 일치도 지표와 신뢰구간을 보고한다.

## 분석과 재현

분석 대상·제외 기준·주요 결과 변수·결측 처리·다중 비교 계획은 자료를 보기 전에 정한다. 점수 분포와 불확실성, 효과 크기와 신뢰구간을 제시한다. 사후에 유리한 문항만 골라 본래의 주 결과처럼 보고하지 않는다. 정성 자료의 부호화 절차, 반례, 연구자의 해석 과정을 함께 기록한다.

부록에는 사용한 커밋, 모형 버전, 비식별 조건 파일, 평가 문항, 루브릭, 분석 코드와 검증 보고서를 포함한다. 원시 학생 텍스트는 재식별 가능성을 검토하고 필요한 동의 범위에서만 공개한다. 논문 제목·초록·결론에서 구현 검증과 교육 효과 검증을 분리한다.
