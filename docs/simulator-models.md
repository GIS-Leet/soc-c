# Geographia Lab 2.0 — 모형 명세와 재현성

이 문서는 시뮬레이터의 **무엇을 계산했는지**, **무엇을 계산하지 않았는지**, **어떻게 검증하는지**를 명시한다. UI의 모형 버전과 실험 파일의 `modelVersion`은 `2.0.0`이다. 교육용 개념 모형의 검증과 실제 자연 현상·학습 효과의 검증을 구분한다.

## 공통 실험 계약

- 같은 모형 버전·입력·지형 격자를 복원하면 같은 수치 결과가 나온다. 카메라 시점과 화면 해상도는 수치 결과에 영향을 주지 않는다.
- 학생 기록은 브라우저 저장소에만 저장한다. 이 페이지들에는 분석 이벤트나 학생 기록 전송 API가 없다. 외부 글꼴과 서울 배경 지도 요청은 별개이며 학생 노트를 포함하지 않는다.
- 노트는 예측·관찰·설명과 최대 8개 비교 조건을 포함한다. JSON은 다시 열기 위한 원본, CSV는 분석용 표다. PNG 또는 SVG는 그림이다. 그림만으로 실험 조건을 완전히 재현할 수 없으므로 JSON을 함께 보관한다.
- 버전·페이지·입력 범위·선택지·지형 격자 길이를 검증한 뒤 파일을 연다. 다른 실험 파일을 잘못 열어도 기존 기록을 유지한다. 정상 파일로 교체할 때 기존 기록이 있으면 먼저 백업 파일을 다운로드한다.
- 파일 내용은 사용자가 편집할 수 있다. 전자 서명이나 성적 인증 자료가 아니다. 논문 분석에서는 원본 파일과 분석 절차를 별도로 보관해야 한다.

## 1. 태양 고도와 사면

입사광은 평행하고 빛다발 전체의 에너지는 일정하다. 태양 고도 α, 태양을 향한 사면 기울기 β에 대해 단위 면적당 수광 비율은 `max(0, sin(α+β))`다. 면적 배율은 양의 수광 비율의 역수다. 비율이 0이면 유한한 투영 면적이 없어 화면에는 수광 없음으로 표시한다. 입사각은 면의 법선과 태양 방향 사이의 각도다.

그림은 동일한 폭의 평행광과 사면의 교차점을 직접 계산한다. 사면 방향이 바뀔 때 수직선도 함께 회전한다. 수평 기준선은 따로 표시한다. 대기 흡수, 지평선의 굴절, 산 그림자, 알베도, 열용량과 기온은 계산하지 않는다. 지평선에 있는 태양과 기울어진 면의 계산도 이 이상화 조건에 해당한다.

검증: 독립적인 방향 벡터의 내적과 각도식을 여러 고도·기울기에서 비교한다. 수광 비율과 면적 배율의 곱이 1인지 확인한다. 30°/수평면에서 0.5와 2, 90°/수평면에서 1과 1이다.

## 2. 공전·자전축·일사

궤도는 원이며 태양 복사상수는 1361 W/m²로 둔다. 기울기 ε와 태양 황경 λ로부터 적위는 `asin(sin ε sin λ)`다. 화면의 3·6·9·12월은 분점과 지점에 맞춘 이상화된 공전 위치이지 특정 연도의 달력 날짜가 아니다. 지구의 축은 공전 중 같은 공간 방향을 유지한다.

태양시 t와 위도 φ에서 태양 고도 h는 `sin h = sin φ sin δ + cos φ cos δ cos(15°(t−12))`로 구한다. 기하학적 지평선에 대한 일출 시각에서 낮 길이를 산출한다. 극야와 백야는 각각 0시간과 24시간으로 처리하고, 극점의 정확한 분점은 대칭 극한의 12시간 규약을 사용한다. 남중 고도는 지평선 아래일 때 음수다.

일평균 일사는 수평면이 받는 **대기권 밖** 일사를 하루 동안 적분한 W/m²다. 지표 일사량이나 기온으로 해석하지 않는다. 굴절·태양의 시직경·타원 궤도·구름·지형 차폐는 제외한다. 관찰점은 선택 위도와 태양시를 나타내는 가상 관찰점이며 특정 경도의 도시가 아니다. 지구 자전 애니메이션의 속도와 크기·거리의 축척도 실제 비율이 아니다.

검증: 3D 축 벡터와 태양 방향의 내적으로 적위를 독립 확인한다. 일사 적분식은 12,000개 시간 표본의 수치 적분과 비교한다(허용 차이 0.002 W/m²). 위도별 면적 가중 평균은 복사상수의 1/4이어야 한다(허용 차이 0.0001 W/m²). NOAA의 분수년 적위 근사는 별도의 기준 함수와 회귀 시험으로 보관하며 실제 달력 모드라고 표시하지 않는다.

근거: [NOAA 계산식](https://gml.noaa.gov/grad/solcalc/solareqns.PDF), [NOAA 계산 가정](https://gml.noaa.gov/grad/solcalc/calcdetails.html), [NASA 계절 설명](https://spaceplace.nasa.gov/seasons/en/).

## 3. 적도 수렴대와 강수 지수

수렴대 중심은 평균 위도 + 진폭 × 계절 사인 함수다. 대륙형(평균 5°, 진폭 15°), 해양형(평균 5°, 진폭 5°, 0.5개월 지연), 대칭형(평균 0°, 진폭 15°)의 **가정값**을 비교한다. 수렴대와의 위도 차이에 폭 7°의 가우스 함수를 적용한 0–100 지수를 제시한다.

이 매개변수들은 관측 자료에 보정한 결과가 아니다. 특정 경도나 지역의 강수량을 예측하지 않는다. 지수에는 mm 단위가 없으며 높은 값이 실제 강수량의 특정 비율을 뜻하지 않는다. 육해 분포, 해류, 산맥과 ENSO는 생략한다. 지도의 띠는 개념적 위치다.

검증: 중심에서 지수 100, 중심으로부터 같은 거리에서 같은 값, 유한한 0–100 범위, 유형별 이동 폭과 위상 차이를 확인한다. 관측 일치도를 주장하지 않는다.

근거: [UCAR 계절풍](https://scied.ucar.edu/learning-zone/storms/monsoons), [NOAA 수렴대](https://www.noaa.gov/jetstream/tropical/convergence-zone).

## 4. 지형 격자

200×200 모형 영역의 129×129 높이 격자다. 같은 시드의 난수열과 고정된 잡음 생성기를 사용한다. 시드만으로 초기 지형을 재생성할 수 있고, 붓 조작 후에는 격자 자체를 저장한다. 실행 취소와 다시 실행은 최대 20개 조작을 보관한다. 드래그 붓은 포인터 이벤트 개수가 아니라 지형 위 이동 거리를 기준으로 일정 간격으로 적용한다.

육지 비율은 셀 중앙의 평균 높이가 해수면보다 높은 셀 비율이며 해안선의 정확한 면적 적분이 아니다. 경사는 셀 중앙 차분, 비고는 최고·최저 격자 높이의 차이다. 단면은 쌍선형 보간, 등고선은 삼각형 셀의 선형 보간을 사용한다. 두 보간 방식은 일반적인 비평면 셀에서 조금 다를 수 있다.

사면 완화는 네 이웃 사이의 대칭 높이 교환이다. 닫힌 경계, 균일한 노드 가중치, 무차원 교환율 0.12, 버튼당 10회 반복을 사용한다. 두 노드 사이의 이동량은 한쪽에서 빼고 다른 쪽에 더해 총 높이 합을 보존한다. 이는 균일한 제어 체적을 가정한 확산 실험이며 삼각형 지표면 아래의 실제 퇴적물 부피나 현실의 침식률을 계산하지 않는다. 격자 간격과 물리적 시간 간격을 보정하지 않았으므로 회수를 연도로 바꾸지 않는다. 붓의 높이 추가·제거는 보존 과정이 아니다.

한반도 이미지는 원본 저장소의 시각 자료를 재사용한다. 출처·공간 기준·고도 보정 정보가 없어 실제 DEM 또는 정량 지형 자료로 주장하지 않는다. 백두산은 칼데라의 절차적 형태다. 모든 높이는 모형 단위다.

격자 파일은 명시적인 little-endian float32와 Base64로 저장한다. 그리기 엔진의 float32 값을 그대로 복원해 압축 과정의 추가 반올림을 피한다. 높이 범위와 배열 길이를 검사한다.

검증: 분석적 평면의 보간·경사·등고선, 시드 재현성, 보존 오차 1e-8 이하(순수 float64 계산), 새 극값 비생성, 평평한 면의 불변성, float32 직렬화 왕복을 시험한다. 화면 엔진에 다시 넣는 float32 반올림 오차는 별도 수지값으로 표시한다.

## 5–6. 지각 작용과 세계 지형

각 시나리오는 절차적으로 정의한 대표 형태와 설명 단계다. 암석의 구성 방정식·응력장·빙하 유동·용식 속도·실제 연대를 풀지 않는다. 애니메이션은 단계 사이의 시각적 보간이며 예측 계산이 아니다.

중앙 기준선에서 현재와 첫 단계의 표면 높이를 비교한다. 지층 블록에서는 변형 전 기준 위치에 대응하는 물질점의 표면 높이를 사용하므로 변형 후 동일한 공간 좌표에서 측량한 단면과는 다르다. 지층 경계의 연속성은 3D 모형에서 살펴본다. 실측 높이와 지역별 일치도를 주장하지 않는다.

검증: 모든 시나리오의 모든 단계 전환, 재생·정지, 유한한 단면 값, 조건 복원과 단면 기록 일치를 검사한다. 개념 설명은 [USGS 지질 자료](https://www.usgs.gov/educational-resources/geology-education), [판 구조론](https://www.usgs.gov/publications/dynamic-earth-story-plate-tectonics), [U자형 골짜기](https://www.usgs.gov/media/images/yosemite-valley-california-example-a-u-shaped-glacial-valley)를 참고한다.

## 7. 서울 대도시권

신도시 대표 좌표는 소수 둘째 자리 수준의 개략 위치이며 행정 경계·사업 지구 중심·인구 가중 중심이 아니다. 시기별 개념도는 기능 변화의 학습을 위한 구조이고, 현재 OpenStreetMap 배경을 과거의 지도로 해석하지 않는다. 교통선도 연결 방향의 그림이며 실제 노선과 개통 현황을 표시하지 않는다.

서울 도심 기준점(37.5665, 126.978)까지의 거리는 평균 지구 반지름 6371.0088km를 사용하는 구면 대권 거리다. 이동시간은 `직선거리 × 우회계수 / 가정 속도 × 60 + 접근·대기시간`이다. 사용자가 가정하는 값과 실제 위치에서 계산한 값을 구분한다. SVG는 개략 경위도 분포 그림으로 축척 지도에 해당하지 않는다.

검증: 거리의 대칭성과 동일점 0, 적도 경도 1°의 약 111.195km, 고정 접근시간이 있는 속도 비교, 시기별 도형 표시와 조건 복원을 확인한다. 실제 통근시간 적합도는 검증하지 않았다.

근거: [LH 주요 연혁](https://www.lh.or.kr/menu.es?mid=a10702030300), [OpenStreetMap](https://www.openstreetmap.org/copyright).

## 렌더링과 접근성

시뮬레이션 수치와 렌더러를 분리한다. 정지한 장면은 요구가 있을 때만 그리고, 화면 밖·숨긴 탭은 그리기를 중단한다. 품질 설정은 균형 30fps/최대 DPR 1.5, 절전 20fps/DPR 1, 선명 60fps/최대 DPR 2이다. 이는 상한 설정이지 모든 기기의 실측 프레임 보장이 아니다.

WebGL 생성 실패 시 2D 단면·평면·공전 대체 보기를 제공하며 계산과 노트는 유지한다. 시나리오 버튼, 슬라이더, 좌표 입력으로 키보드 조작을 지원한다. 3D 시점의 세밀한 마우스 조작을 키보드와 동일하게 구현한 것은 아니며 핵심 학습 기능의 수치·단면 대안을 제공한다. 그래프의 색 이외에 선 모양·숫자 표·텍스트를 사용한다.

자동 접근성 검사는 WCAG A/AA 규칙에 대한 도구 검사다. 전체 WCAG 적합성, 특정 보조 기술과의 사용성 또는 실제 학생의 학습 효과를 보증하지 않는다.
