Original downloads are unmodified; checksums were compared with the source API metadata. The height images perturb shading normals only, not the terrain mesh. These generic surface samples do not identify the actual rocks or vegetation of Baekdu Mountain or any particular study site. All files are served locally; students' browsers do not contact Poly Haven.

## Earth image

`earth-june.jpg` is NASA's **Blue Marble Next Generation, June 2004, with topography and bathymetry**, downloaded unchanged at 5400 × 2700 pixels. Source: [NASA Earth Observatory collection](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-topography-bathymetry/), [original JPEG](https://eoimages.gsfc.nasa.gov/images/imagerecords/73000/73726/world.topo.bathy.200406.3x5400x2700.jpg). Credit: NASA Earth Observatory, Reto Stöckli / NASA GSFC.

NASA permits educational and informational uses of this material under its [media usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/). No NASA endorsement is implied. The browser resamples the original to a 2048 × 1024 canvas before uploading it to the GPU. The composite is a static geographic backdrop: changing the simulated month does not change its vegetation or snow. ITCZ clouds are a deterministic illustrative opacity field, not satellite cloud observations.
